## AI Approach
For this project, I used AI to help me create my personal website using HTML and CSS. I used AI as a tool to assist me with the development process and to help me create the structure and styling of the website.

Although I used AI to help write some of the code, I understand what the code in my index.html and style.css files does. I understand that HTML is used to create the structure and content of the webpage, while CSS is used to control the appearance, layout, colours and styling.

I reviewed the code generated by AI and made changes to personalise the website and make it suitable for my project. Using AI helped me develop the website more efficiently while also allowing me to learn and understand how the HTML and CSS work together.

Overall, I used AI as an assistance tool rather than relying on it to complete the project without understanding the code.
